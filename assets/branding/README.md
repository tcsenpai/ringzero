# ringzero branding

The logo is the "R0" die: a red chip in the middle of a CPU package. Images were generated by the project
author with Lumo and processed for the repo (transparent logo, 256-color PNGs, JPEGs at most 1600 px wide).

## Palette

Sampled from the logo and the brand images.

| Role | Hex | Where |
|---|---|---|
| R0 red (primary) | `#C6140A` | the die, links, the shell prompt, highlights |
| Red light | `#E8473C` | hover, glows, emphasis on dark |
| Red deep | `#5C231C` | shadows, borders on dark |
| Pin gold (accent) | `#C9A45C` | secondary accent, tool lines |
| Package gray | `#6B6B6B` | muted text, dim lines |
| Graphite | `#1E1F22` | surfaces on dark |
| Black | `#050505` | background |
| Off-white | `#ECEAE6` | text on dark |

Terminal mapping (ANSI, for the shell colors): prompt red bold, agent answer default, `[tool]` gold (yellow),
`[memory]` and statistics gray (dim), confirmations and errors bright red.
